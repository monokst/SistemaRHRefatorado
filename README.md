💼 Sistema de Gestão de Recursos Humanos

Este projeto acadêmico foi desenvolvido com o objetivo de criar uma solução prática para a gestão de Recursos Humanos, voltada especialmente para microempreendedores, pequenos empresários e comércios de bairro.

A proposta é entregar um sistema leve, intuitivo e de fácil utilização, permitindo o controle das principais informações de RH sem a necessidade de ferramentas complexas ou alto investimento.

Com ele, é possível cadastrar, editar, consultar e excluir funcionários (CRUD), além de gerenciar cargos, salários e visualizar relatórios com uma visão geral dos dados cadastrados.

O sistema conta com autenticação de acesso, garantindo que apenas usuários autorizados possam utilizar as funcionalidades, além de validações importantes como CPF único, campos obrigatórios e verificação de datas.

Além das funcionalidades, o projeto foi desenvolvido seguindo boas práticas de programação, com foco em organização, escalabilidade e manutenibilidade do código, aplicando conceitos de Design Patterns, incluindo o Builder Pattern, Command, factory, decorator e a arquitetura MVC (Model-View-Controller), proporcionando uma estrutura mais limpa, reutilizável e de fácil manutenção.

🚀 Tecnologias utilizadas: Java | MySQL | HTML | CSS | Javascript
